# 🌍 Local Business Discovery Platform

A modern React + Tailwind CSS web application that helps users discover and explore local businesses such as cafes, restaurants, gyms, and other services.

## 🚀 Features

### 🔍 Business Discovery
- Search businesses by name
- Filter businesses by category
- View business details

### ❤️ Favorites
- Add businesses to favorites
- Favorites stored using Local Storage
- Quick access to favorite businesses

### 🌙 Dark Mode
- Toggle between Light and Dark themes
- User preference saved locally

### ⭐ Ratings & Reviews
- View business ratings
- Customer review section
- User feedback support

### 📍 Location Features
- Google Maps integration
- Nearby business finder
- Business location details

### 🤖 Smart Recommendations
- AI-inspired business recommendations
- Trending business highlights
- Business of the Day

### 📊 Analytics Dashboard
- Business visit tracking
- Popular business insights
- User engagement metrics

### 🏆 Advanced Features
- Business comparison
- Leaderboard of top-rated businesses
- Special offers and promotions
- Events section
- User profile dashboard
- Virtual business tour gallery

---

## 🛠️ Technologies Used

- React.js
- React Router DOM
- Tailwind CSS
- JavaScript (ES6+)
- Local Storage API
- Vite

---

## 🎯 Project Goal

The goal of this project is to create a platform that helps users discover and compare local businesses beyond food delivery apps. Unlike apps focused only on restaurants, this platform supports multiple business categories such as:

- Cafes ☕
- Restaurants 🍛
- Gyms 🏋️
- Hospitals 🏥
- Salons 💇
- Local Services 🔧
